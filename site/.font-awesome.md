- **Families:** classic, duotone, sharp, sharp-duotone

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

Icons are used via Web Awesome's `<wa-icon>` component. Do **not** use `<i class="fa-...">` tags — this project uses Web Awesome components exclusively.

```astro
<!-- Classic solid (default — no attributes needed) -->
<wa-icon name="book-open"></wa-icon>

<!-- Classic regular (Pro) -->
<wa-icon name="book-open" variant="regular"></wa-icon>

<!-- Classic light (Pro) -->
<wa-icon name="book-open" variant="light"></wa-icon>

<!-- Classic thin (Pro) -->
<wa-icon name="book-open" variant="thin"></wa-icon>

<!-- Brands -->
<wa-icon name="github" family="brands"></wa-icon>

<!-- Duotone solid (Pro) -->
<wa-icon name="book-open" family="duotone"></wa-icon>

<!-- Sharp solid (Pro) -->
<wa-icon name="book-open" family="sharp"></wa-icon>

<!-- Sharp duotone (Pro) -->
<wa-icon name="book-open" family="sharp-duotone"></wa-icon>
```

**Do NOT use `library="fas"` etc.** — `library` is for custom registered icon libraries only.
FA icons are selected via `family` + `variant` attributes on `<wa-icon>`.

## Conventions

- Kit code is hardcoded in `src/layouts/Layout.astro` as `data-fa-kit-code` on the `<html>` element.
- Web Awesome reads `data-fa-kit-code` automatically for all `<wa-icon>` Pro icon lookups.
- Icon names use kebab-case (e.g., `book-open`, not `faBookOpen`).
- Default family is `classic`, default variant is `solid` — omit both for the most common case.
